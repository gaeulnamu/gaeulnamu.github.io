gaeulnamu-publisher 앱

gaeulnamu-publisher는 채널 운영자가 자기 컴퓨터에서 쓰는 게시 도구입니다. 운영자가 직접 찍고 편집한 가을나무 영상을 운영자 본인의 YouTube 채널, Instagram 계정, Facebook 페이지에 정해진 시각에 올립니다. 다른 사람이 로그인하거나 사용하는 기능은 없습니다.

  • YouTube Data API: 운영자 채널에 영상 올리기(videos.insert), 운영자 채널에 이미 올린 영상 목록 읽기(중복 게시 방지)
  • Instagram Graph API, Facebook Graph API: 같은 영상을 릴스로 게시

About (English)

Gaeulnamu is a short-video channel about a dog named Gaeulnamu. gaeulnamu-publisher is a private desktop tool used only by the channel owner. It uploads the owner's own videos to the owner's own YouTube channel, Instagram account and Facebook Page on a schedule. It uses the YouTube Data API only to upload videos to the owner's channel and to list the owner's uploaded videos so the same video is not posted twice. No other users sign in to or use this tool.
